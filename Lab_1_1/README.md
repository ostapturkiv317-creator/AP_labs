## Умова завдання

Виконати вказані дії на переведення чисел з однієї системи числення в іншу (завдання однакові для всіх варіантів):

1. (10 → 2) До номера дня народження додати номер місяця народження та останню цифру року народження; отримане число перевести у двійкову систему.
2. (2 → 10) Двійкове число із завдання 1 записати «задом наперед» і перевести в десяткову систему.
3. (10 → 16) Те саме число, що в завданні 1, перевести в шістнадцяткову систему.
4. (16 → 10) Шістнадцяткове число із завдання 3 записати «задом наперед» і перевести в десяткову систему.
5. (2 → 16) Двійкові числа із завдань 1 та 2 перевести в шістнадцяткову систему.
6. (16 → 2) Шістнадцяткові числа із завдань 3 та 4 перевести в двійкову систему.

## Відповідь

```
Вхідні дані: дата народження 15.02.2009
  день = 15, місяць = 2, остання цифра року = 9
  X = 15 + 2 + 9 = 26
```

### Завдання 1. (10 → 2): 26₁₀ → ?₂

```
 №  |  x  | x / 2 | x % 2
----+-----+-------+------
 0  | 26  |  13   |  0
 1  | 13  |   6   |  1
 2  |  6  |   3   |  0
 3  |  3  |   1   |  1
 4  |  1  |   0   |  1   <- результат 0, STOP

Розряд:  4 3 2 1 0
Цифра:   1 1 0 1 0

26(10) = 1 1010(2)
Перевірка: 1*16 + 1*8 + 0*4 + 1*2 + 0*1 = 26
```

### Завдання 2. (2 → 10)

```
11010 записане «задом наперед»: 01011 = 1011(2)

Цифри:     1    0    1    1
Розряди:   3    2    1    0
Множники:  2^3  2^2  2^1  2^0
Значення:  8    4    2    1

1*8 + 0*4 + 1*2 + 1*1 = 11

01011(2) = 11(10)
```

### Завдання 3. (10 → 16): 26₁₀ → ?₁₆

```
 №  |  x  | x / 16 | x % 16
----+-----+--------+-------
 0  | 26  |   1    | 10 (A)
 1  |  1  |   0    |  1     <- STOP

26(10) = 1A(16)
Перевірка: 1*16 + 10*1 = 26
```

### Завдання 4. (16 → 10)

```
1A записане «задом наперед»: A1(16)

Цифри:     A     1
Розряди:   1     0
Множники:  16^1  16^0

10*16 + 1*1 = 161

A1(16) = 161(10)
```

### Завдання 5. (2 → 16)

Двійкове число ділимо на тетради (по 4 біти справа наліво), кожну тетраду замінюємо шістнадцятковою цифрою.

```
1 1010(2)  = 0001 1010 = 1 A  = 1A(16)
01011(2)   = 0000 1011 = 0 B  = B(16)
```

### Завдання 6. (16 → 2)

Кожну шістнадцяткову цифру замінюємо тетрадою з 4 бітів.

```
1A(16) = 0001 1010(2) = 11010(2)
A1(16) = 1010 0001(2) = 10100001(2)
Перевірка: 128 + 32 + 1 = 161
```

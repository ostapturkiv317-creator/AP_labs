## Умова завдання

Дано два числа:

- **A**: до номера дня народження додати номер місяця народження та останню цифру року народження;
- **B**: до номера свого варіанта додати 20 та число, записане двома останніми цифрами року вступу.

Отримані числа перевести у двійкову систему і обчислити (відповідь у двійковій та десятковій системах):
`A & B`, `A | B`, `A ^ B`, `~A`, `~B`, `A << 1`, `B << 1`, `A >> 1`, `B >> 1`.

## Відповідь

### Обчислення вхідних даних

```
Дата народження 15.02.2009, варіант 33, рік вступу 2026

A = 15 + 2 + 9  = 26
B = 33 + 20 + 26 = 79
```

### Переведення у двійкову систему

```
A = 26:                          B = 79:
 x  | x/2 | x%2                   x  | x/2 | x%2
 26 |  13 |  0                    79 |  39 |  1
 13 |   6 |  1                    39 |  19 |  1
  6 |   3 |  0                    19 |   9 |  1
  3 |   1 |  1                     9 |   4 |  1
  1 |   0 |  1                     4 |   2 |  0
                                   2 |   1 |  0
                                   1 |   0 |  1

A = 0001 1010(2)                 B = 0100 1111(2)
```

### Таблиця результатів (8-бітове представлення)

```
 вираз  | 7 6 5 4 3 2 1 0 | десяткове
--------+-----------------+----------
 A      | 0 0 0 1 1 0 1 0 |    26
 B      | 0 1 0 0 1 1 1 1 |    79
--------+-----------------+----------
 A & B  | 0 0 0 0 1 0 1 0 |    10
 A | B  | 0 1 0 1 1 1 1 1 |    95
 A ^ B  | 0 1 0 1 0 1 0 1 |    85
 ~A     | 1 1 1 0 0 1 0 1 |   229
 ~B     | 1 0 1 1 0 0 0 0 |   176
 A << 1 | 0 0 1 1 0 1 0 0 |    52
 A >> 1 | 0 0 0 0 1 1 0 1 |    13
 B << 1 | 1 0 0 1 1 1 1 0 |   158
 B >> 1 | 0 0 1 0 0 1 1 1 |    39
```

Пояснення:
- `&`: результат 1 лише там, де обидва біти дорівнюють 1;
- `|`: результат 1 там, де хоча б один біт дорівнює 1;
- `^`: результат 1 там, де біти різні;
- `~`: кожен біт інвертується (0→1, 1→0);
- `<< 1`: біти зсуваються на 1 позицію ліворуч, справа дописується 0 (еквівалентно множенню на 2);
- `>> 1`: біти зсуваються на 1 позицію праворуч, зліва дописується 0 (еквівалентно цілочисельному діленню на 2).

## Висновки

У ході лабораторної роботи я навчився виконувати бітові операції: порозрядні «і», «або», «виключне або», заперечення, а також зсуви ліворуч і праворуч. Переконався, що зсув ліворуч на 1 розряд множить число на 2 (26 → 52, 79 → 158), а зсув праворуч ділить його націло на 2 (26 → 13, 79 → 39).
